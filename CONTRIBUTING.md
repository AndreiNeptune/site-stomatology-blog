# Contributing to Luna Dental

Welcome! We follow a strict set of standards to ensure the codebase remains "premium" and maintainable.

## 📝 Commit Standards

We use **Conventional Commits**:
- `feat:` for new features
- `fix:` for bug fixes
- `chore:` for maintenance/setup
- `style:` for UI/CSS changes without logic changes
- `refactor:` for code improvements

## 🛠️ Workflow

1. Ensure your `.env.local` is correctly configured.
2. Run `npm run lint` before committing.
3. Keep components small and reusable in `src/components`.
4. Use Tailwind CSS for all styling; avoid inline styles.

## 🚀 Deployment

The project is automatically deployed via Netlify on pushes to `main`.
